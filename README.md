# CheckYourDirectory - 文件夹校验工具

## 简介

CheckYourDirectory 是一个用于校验文件夹内容的工具，它可以生成文件夹中所有文件的校验值，并支持后续比对文件夹内容是否发生变化。该工具支持多种哈希算法，包括 MD5、SHA1、SHA256 和 SHA512。

## 功能特性

* 生成文件夹中所有文件的校验值
* 将校验信息保存为 JSON 文件
* 加载已有的校验文件
* 比对当前文件夹与校验文件的差异
* 支持多种哈希算法
* 直观的比对结果显示

## 系统要求

* Windows 操作系统
* .NET Framework 4.7.2 或更高版本

## 使用方法

### 1. 生成校验文件

1. 点击"浏览..."按钮选择要校验的文件夹
2. 从下拉菜单中选择哈希算法（默认为 MD5）
3. 点击"生成校验文件"按钮
4. 选择保存位置和文件名（默认为 folder\_checksum.json）
5. 等待校验完成

### 2. 打开校验文件

1. 点击"打开校验文件"按钮
2. 选择之前保存的 JSON 校验文件
3. 文件内容将被加载到内存中用于后续比对

### 3. 比对文件夹

1. 确保已加载校验文件
2. 点击"浏览..."按钮选择要对比的文件夹
3. 点击"比对文件夹"按钮
4. 等待比对完成
5. 查看比对结果（新增、删除和修改的文件）

## 校验文件格式

校验文件使用 JSON 格式存储，包含以下信息：

```
{
  "HashAlgorithm": "MD5",
  "CreationTime": "2023-01-01T00:00:00",
  "FileChecksums": {
    "file1.txt": "d41d8cd98f00b204e9800998ecf8427e",
    "subfolder/file2.txt": "0cc175b9c0f1b6a831c399e269772661"
  }
}
```
